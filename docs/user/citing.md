# Citing consilium

Consilium is released under the MIT License (`LICENSE`). If you use it —
the agents, the test-gate pattern, or the prompt-plus-eval-fixture
methodology — please cite it.

`CITATION.cff` at the repo root is the machine-readable source of truth
(CFF 1.2.0). GitHub reads it directly: the "Cite this repository" button on
the repo page generates APA or BibTeX from it without you needing to copy
anything by hand.

## BibTeX

```bibtex
@software{liu2026consilium,
  author  = {Liu, Dunyu},
  title   = {Consilium},
  version = {1.27.0},
  date    = {2026-09-18},
  url     = {https://github.com/dunyuliu/consilium},
  license = {MIT}
}
```
