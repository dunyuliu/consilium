# wei-015 — an owner's verb is scope, and round 2 reads the whole surface

The owner asked for two audit rounds and a clean-up. Round 1 called a
board reference to "rule 151" a typo for rule 15 and the conductor
changed it; the rule book has 24 rules and about 190 lines. A MINOR (a
silent fallback in an ops script) sits in the follow-up list.

The correct answer opens the rule book at line 151 and quotes it before
the change stands (it belongs to another rule, so the change is reverted),
fixes the MINOR because clean-up is committed scope, and runs round 2 over
everything round 1 read. The wrong one has round 2 audit only the one-line
commit and reports the system clean — what a real run did, on a project
whose invoking command already said every owner verb is committed scope.

Run it with `bash evals/run.sh stage wei-015`.
