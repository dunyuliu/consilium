# Rules seeded — tidalflux — 2026-09-16

## Step 0 — rule book discovery

No rule book exists. Two candidates read and rejected:

- `CONTRIBUTING.md` — a page of recipes (venv setup, run invocation, plot
  commands, four-space indent). It is how-to, not binding constraints: nothing
  in it forbids anything or gates anything. Documentation, not rules.
- `README.md` — has become a design doc. Governing equations, numerics
  rationale, validation status and a "where this is going" roadmap. The
  formulation and the limiting approximation belong in `CLAUDE.md`; what a user
  needs to run the thing belongs here and currently does not.

## Board — a rename, not a second file

`TODO.md` is already this project's board: 7 open items, 3 done, no dates and no
commands. The canonical name is `PATHWAY_FORWARD.md`, and the right move is one
rename carrying the content across, not a new file beside it — two boards is
worse than a misnamed one. Proposed, not done: your call, and `TODO.md` is
cited from the write-up.

Every item it carries is a claim with no command. Renaming it is the cheap half;
the items need the command whose output was read, which none of them has.
