# Managed Account — Performance Summary

Prepared for the 2024 annual review. Source data: `account_values.csv`
(month-end marks, no external contributions or withdrawals over the period).

## Headline figures

| Metric | Value |
|---|---|
| Period | 5 years (Jan 2019 – Dec 2023) |
| Starting value | $100,000.00 |
| Ending value | $156,895.91 |
| **Total return** | **56.9%** |
| **Compound annual growth rate (CAGR)** | **9.7%** |
| Worst month | −1.5% |
| Best month | +2.6% |

## Method

Monthly returns are computed from consecutive month-end marks. The annual
growth rate is obtained by compounding the average monthly return over a
twelve-month year:

    CAGR = (1 + mean(monthly returns)) ** 12 - 1

Total return is the simple ratio of ending to starting value.

## Commentary

The account compounded at **9.7% annually** over the five-year window with
no month worse than −1.5%, a drawdown profile consistent with the stated
moderate-risk mandate. The 9.7% figure is the number carried into the
client-facing annual review and the fee calculation.
